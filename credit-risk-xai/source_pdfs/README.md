## Как использовать на защите

1. Для цитаты используйте DOI из таблицы `../comparative_table_26_fulltext.md`, а не имя локального файла.
2. Для источников из первого раздела откройте PDF и покажите титульную страницу, авторов, журнал/репозиторий и DOI.
3. Для 9 позиций второго раздела не говорите «полный текст изучен локально». Корректная формулировка: «библиографическая запись и официальный URL верифицированы; локальная копия недоступна в текущем доступе». Это честнее и доказательнее, чем выдавать страницу издателя за PDF.
